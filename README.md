# Curso de C para Software Embarcado Automotivo

Repositório de estudos em linguagem C utilizando Termux, com foco em
software embarcado automotivo.

## Conteúdo

- Aula 1: compilação e primeiros programas
- Aula 2: variáveis e entrada de dados
- Aula 3: estruturas condicionais e validações
- Aula 4: laços de repetição e menu com switch
- Projeto contínuo: computador de bordo BordoC

## Ambiente

- Android
- Termux
- Clang
- Git
