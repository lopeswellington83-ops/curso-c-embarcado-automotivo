# BordoC

Computador de bordo automotivo desenvolvido em linguagem C como
projeto de estudo de software embarcado e protocolos automotivos.

## Versão atual

Versão inicial baseada no projeto desenvolvido durante as aulas 1 a 4.

## Funcionalidades atuais

- Menu interativo
- Exibição de dados do veículo
- Alteração de valores simulados
- Validação de sensores
- Alertas de temperatura, bateria, combustível e RPM
- Simulação de aceleração
- Simulação de aquecimento

## Objetivos futuros

- Organização do código em funções
- Uso de estruturas
- Computador de viagem
- Histórico de alertas
- Simulação de mensagens automotivas
- Diagnóstico OBD-II
